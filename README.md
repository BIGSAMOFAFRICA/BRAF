# BRAF React landing page

A responsive React landing page for the Bayonle Rasheed Akinbile Foundation. It includes the official logo and the supplied Higher Consciousness conference flyer.

## Run locally

1. Install Node.js if it is not already installed.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local address shown in the terminal.

To create a production build, run `npm run build`. Vite writes the finished site to `dist/`.

## Update the site

- Edit page content and repeated lists in `src/App.jsx`.
- Edit colors, layout and mobile styling in `src/styles.css`.
- Replace images in `public/assets/` to update the logo or event flyer.
- The Eventbrite link is set near the top of `src/App.jsx` in `eventUrl`.

The event date, venue, registration details and foundation contact information reflect the supplied flyer and foundation details. The Board of Trustees section is ready for confirmed names.
